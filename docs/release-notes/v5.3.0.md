# Suijin v5.3.0 — Field-hardened

Every change in this release came out of live field engagements (target
names withheld) — each field run's bug report drove a fix, and the new
crash-log system makes the next ones diagnosable in seconds.

## What landed

**The engagement console UI, rebuilt from field runs** — the operator
finally sees what the agent sees, and a rendering bug can no longer kill
an engagement:

- One iteration = one rendered block: thinking (dim blue), said (cyan),
  the command in a syntax-highlighted mini-terminal, output rendered as
  markdown or syntax-highlighted by content type. No truncation anywhere.
- A pinned strip doubles as the thinking spinner (20fps) showing phase ·
  iteration · tokens · cost · FLAG/CRED/FT counters.
- Uncrashable renderer: every render method is guarded — failures log to
  `outputs/logs/ui_crash.log` and fall back to plain text. Both crash
  logs have already caught real field bugs.
- No silent endings: exactly one termination banner per run — COMPLETE /
  DECLINED / OPERATOR STOP / FAILED / NO OUTPUT — with what happened and
  what to do next.
- Instant Ctrl+C. A 15-command pause console (`/objective` `/phase`
  `/focus` `/skip` `/finish` `/loot` `/jobs` `/kill` `/cost` and the
  classics) that can change the engagement's course mid-run.

**The operator authorization workflow** — `suijin authorize <domain>`
puts authorization on file (program, auth id, 90-day expiry, subdomain
coverage) and it rides every engagement order, so the agent never
re-litigates it. `suijin bb-scope <program-url>` pulls a program's real
scope via bugscope (5 platforms, operator token per-call, never stored)
as an advisory binding. The `fetch_authorization_page` tool gives the
agent eyes-on verification with an explicit verdict doctrine: a
Cloudflare/WAF block means the page exists — nonexistent pages 404 — and
that is ample.

**The supervisor became a battle-buddy** — four interference bugs fixed
(it used to demand verification with a tool that doesn't exist, count
research as bookkeeping, and interrupt mid-exploitation), plus 52
tactical follow-up heuristics (JWT spotted → jwt_inspect, SQLi confirmed
→ sqlmap extraction, AIza key → google_key_probe, 403 wall → verb
tampering, …) that fire only when pathology is silent, cooldown-gated.

**Cost you can trust** — per-model pricing completed (the default HF
model silently fell to the fallback rate; the estimate path was dead
code recording zero), estimate fallbacks for every provider, honest
`priced` flag, and provider retry noise silenced. Provider flakes get
one automatic restart before an engagement ends.

**New tools** — `js_bundle_analyze` / `google_key_probe` /
`source_map_probe` (SPA attack-surface mining in one call — built from
a field run where the agent hand-rolled three iterations of broken
curl+grep), every core tool taught in the prompt registry, and
mcp_playwright hardened (missing dependency fails fast with
instructions instead of a 30-second hang and a false "Browser timeout").

**A workspace that survives you** — state lives at
`~/.suijin/workspace`, outside any repo copy: sessions, memory, the
authorization ledger, bugscope pulls and reports survive re-clones,
reinstalls and dev-tree wipes. The installer migrates legacy content
and asks install-type first (normal vs dev — dev is the default inside
a checkout, live symlink, edits picked up without reinstalling).

## Try it

```bash
suijin authorize your-target.com --program h1 --id <auth-id>
suijin bb-scope https://hackerone.com/<program>   # optional, advisory
suijin            # Red Team → objective → run
```

Pause anytime with Ctrl+C: `/objective` to change course, `/loot` to
see what's captured, `/finish` to wrap up.
