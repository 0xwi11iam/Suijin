### 2. Self-critique — the agent grades itself
After every engagement, an LLM pass over the execution trace produces
what-worked / what-wasted / missed-leads / tactics-to-remember. The
report lands in `outputs/reports/critique_*.md`; the tactics go into
the knowledge graph, so the next engagement starts smarter
(`check_knowledge` surfaces them). Config-gated (`self_critique: true`),
never fatal.

### 3. Sparring mode — detector regression gates
`suijin spar` fires a fixed attack/benign volley through the REAL blue
detector, scores precision/recall/F1, and compares against stored
baselines: **STABLE / IMPROVED / REGRESSION**, with
`--fail-on-regression` for CI semantics. Detector drift becomes visible
the moment it happens, not after an incident.

### 4. Deploy: four turnkey paths
| Platform | One command | Notes |
|---|---|---|
| macOS / Linux | `curl ... install.sh \| bash` | interactive start (OS + pip, detected defaults), FULL dependency auto-resolution, colored step-by-step |
| Docker (any host) | `cp .env.example .env && ./docker.sh run` | named volume keeps state across rebuilds; colima + Desktop |
| Windows | `powershell -File install.ps1 install` | Docker-only by policy (native refused with a clear pointer) |
| Existing Kali | `curl ... kali-setup.sh \| bash` | full arsenal into `/opt/suijin`; hard-stops on non-Kali |

Docker image is minimal-footprint by design: `kali-linux-core` + a
curated toolset; metasploit behind `--build-arg WITH_METASPLOIT=1`.

## Fixed in this release
- **Kernel journal data-loss bug**: two rotations within one second
  silently overwrote each other. Rotation is now collision-proof
  (`journal-<ts>-<n>.log`); the concurrency stress test forces rotation
  deterministically on every Python version.
- MCP server sys.path bootstrap (broken by the console move, masked by
  an egg-info install).
- `ask_operator` parse rejection (prompt taught it, nodes handled it,
  parser alone refused it).
- Catalog parity holes (10 core + 4 KB tools were routed-but-invisible).
- 7 vacuous test skips became 11 live behavioral tests.
- CI: orphaned frontend/rust steps removed; deploy-scripts sanity step
  added (executes exactly as the runner receives it); fresh-checkout
  worktree verification is now the standard for CI changes.

## Breaking / policy changes
- **No native Windows runtime** — Windows is Docker-only via
  `install.ps1`; `execute_terminal` refuses on win32 with a pointer.
- Old import paths (`suijin.tools.*`, `suijin.core.*`, etc.) remain
  gone since the v4.1 clean break — no shims.
- `config.json` no longer ships as wheel package-data (operator-local
  keys; auto-created with defaults on first run).
- Web dashboard removed in v4.2 (CLI + TUIs + MCP remain; the `watch`
  verb kept the blue scoring).

## Upgrade
Existing installs: `install.sh` again (or `git pull` + pip install -r
suijin/requirements.txt inside your venv). Workspaces migrate
automatically: artifacts consolidate under `suijin_agent/outputs/`,
engagement state + operator configs move to the workspace, KB/caches
move to `suijin_agent/caches/` — all idempotent, nothing deleted.
