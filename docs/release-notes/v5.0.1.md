# Suijin v5.0.1 — Stable

**Status: STABLE.** The modular OS is complete and production-shaped:
every line of application code lives in `suijin/modules/` behind a
stdlib-pure kernel, the agent sees its full 265-tool arsenal in a
6.4k-token prompt, and it works quietly by default.

## What "Stable" means here

1. **Architecture frozen in green**: kernel purity, module boundaries,
   import-graph, catalog parity, and the 10k prompt budget are all
   CI-enforced contracts — the structure cannot silently rot.
2. **Local == CI**: `scripts/verify-ci.sh` replays GitHub's exact steps
   against a fresh worktree + clean venv before you push. Every incident
   class it was built to catch, it caught.
3. **Everything since v5.0.0** is hardening and capability, no churn:

   - **Stealth mode** (ON by default, zero performance loss): sticky
     realistic browser identity, burst-limited pacing, tool-level rate
     caps for loud tools; 33 packs swept clean of scanner signatures
   - **Agent competence rebuild**: coding-agent-simple decision loop
     (4-field JSON, tolerant parser), fireteam sub-agents that can't be
     wasted (usefulness gates, evidence compression, non-blocking teams),
     scratchpad + structured observations
   - **REAL battle**: the actual LLM agent attacks the live vulnerable
     lab; blue's recall scored against ground truth from red itself
   - **Genuine token counter**: API-reported vs client-estimated with
     per-provider attribution (`suijin tokens`)
   - **bugscope**: 5-platform bug-bounty scope scraper (bbscope method,
     SSL-verified, reference-accurate adapters)
   - **Neo4j-ready knowledge graph**: same API, one config switch
     (`kg_backend`), fail-safe to JSON
   - Ctrl-C clean everywhere; tool-not-found asks the operator
