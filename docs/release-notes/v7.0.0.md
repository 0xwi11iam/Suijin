# v7.0.0 — The Command Center Release

One screen now commands the swarm — and the swarm remembers. The
operator console turns N terminal windows into one command center, and
the knowledge graph stops being a suggestion the agent might check and
becomes something it physically cannot skip.

### Added — the operator console (`suijn operator`)
- The dashboard: agent cards (hex ids, phase, live severity, cost),
  per-agent **iteration history** (page back through any session's
  turns), the mesh chat (bottom-anchored, newest always visible), and
  System One decision-layer status (engine, model state, decisions,
  fallbacks) straight from the per-turn digests
- The command line:
  - `/say <msg>` — the operator broadcasts to every agent (they read
    it when building their next context)
  - `/pause [msg]` — hold **all** agents between turns; an optional
    message rides the guidance channel and is read on resume
  - `/su <hex>` / `/su root` — become an agent: `/state /audit /cost
    /findings /note /objective /panic`, or type free-text guidance
    straight into its context; predictions follow the identity
  - `/exploits /tail /sort /filter /clear /refresh` — inspect and
    rearrange the field
  - command history recall (`↑/↓`), usage feedback above the box
- Keyboard-first: `tab` cycles the focus ring (cards → details →
  input → mesh → overview), `j/k` page the roster, `←→` walk
  iteration history; typing only exists in the input focus
- `--demo` renders the whole experience with mock agents (three
  iterations of history each, confirmed + failed POCs, a hung node)

### Added — the knowledge graph grows teeth
- **Neo4j backend is live**: one config switch (`kg_backend`), local
  Docker with a persistent volume, loud fallback to JSON when the
  server is down, idempotent JSON → Neo4j migration
- **Enforced read**: every think context carries the target's KG
  summary as a section — verified constraints, blocked patterns, WAF
  rules are impossible to skip; `check_knowledge` stays for deeper
  queries
- **Confirmed exploits fan out** without model choice: a
  terminal-verified POC writes a `verified` constraint to the graph,
  broadcasts a `[system]` line every peer sees, and files an
  engagement note
- **Machine comms**: phase transitions broadcast automatically; the
  groupchat prompt carries a hard cadence rule (≥1 broadcast per 5
  iterations — lane claim, verdict, or dead end)

### Fixed — the live-engagement class
- **Parallel agents launched in the same second silently merged into
  ONE engagement** — one shared audit trail, findings mixed between
  sessions. Engagement dirs are uniquified and the console matches
  audits by engagement dir, not timestamp guesswork
- **A closed window is gone**: SIGHUP now takes the same save-and-exit
  path as SIGTERM; dead-pid nodes are dropped and pruned; pid
  recycling can't fake liveness past 24h
- **Only machine-proven exploits count**: agent-claimed findings
  (behavior notes, false positives, a hallucinated lab flag) no longer
  inflate severity totals — the console counts POC-verifier CONFIRMED
  entries only, cross-engagement deduped
- Audit findings record once per (type, endpoint); mesh chat carries
  date+time stamps and hex agent ids

### Lab/real isolation
- Class-transfer advice ignores lab catalogs — a lab decoy can never
  whisper into a real engagement
- `FLAG{...}`/`HTB{...}` markers on non-lab targets are REJECTED as
  contamination at record time
- Cheatsheet entries carry origin provenance from their engagement

### Docs
- README rewritten product-first (who it's for, what a run looks like)
- The retired defensive stack scrubbed from every living doc; ADR-002
  carries its superseded-in-practice note

2,798+ tests green.
