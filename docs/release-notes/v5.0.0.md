# Suijin v5.0.0 — The 50

**All 50 roadmap features complete.** Six waves, ~40 gated commits,
one architecture that held throughout: everything is a module, the
kernel is the only coupling surface, and every feature shipped with
tests.

## The numbers

| | |
|---|---|
| Roadmap features | **50/50** (waves 1–6) |
| Test suite | **1,160 passed** |
| Boot estate | 149 units / 256 tools / 0 skipped |
| Install paths | 4 (native, Docker, Windows-Docker, existing-Kali) |

## What the 50 bought you

**Money** — hard cost governor (spend cannot cross `max_cost_usd`),
efficiency leaderboard, cost forecasts, failover telemetry, prompt
budget profiler.

**Intelligence** — findings get an independent second evidence path
(artifact-match verification), a hostile peer review, and confidence
tags; dead-end and payload-class detectors force strategy switches;
context compaction survives long engagements; adversary profiles
(stealth/loud/insider) change posture.

**Knowledge** — per-target operational memory, fingerprint deltas and
drift alerts, a tamper-evident hash-chained evidence vault, finding
dedup, probability-weighted attack paths, CVE→tool advising, KB
freshness prompts.

**Workflow** — exec/technical/compliance report templates in four
languages, reusable engagement templates with cron scheduling,
webhooks, offline client-portal HTML bundles, session forking at any
iteration, animated session theater.

**Blue team** — red traces replay through the real detector, deception
effectiveness metrics, SOC playbooks, an FP feedback loop with a
persistent allowlist, incident timelines, nginx/Apache adapters, canary
tripwires, DNS-tunnel + beaconing exfil detection.

**Platform** — the marketplace: decentralized indexes (any URL),
hash-pinned installs, rollback-safe updates, `suijin market` — and it
works out of the box: a bundled 146-pack catalog ships in the wheel as
the offline fallback index; typed MCP schemas for every pack tool;
self-promoted learnings (`suijin skills promote`); skill decay pruning
(`suijin skills decay`); knowledge-graph mermaid export
(`suijin kg graph`).

## Upgrade
`install.sh` again, or `git pull` + pip install. Workspaces migrate
idempotently. New optional config: `max_cost_usd`, `cost_warn_pct`,
`adversary_profile`, `self_critique`.
