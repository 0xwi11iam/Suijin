# v7.1.0 — The Clean Memory Release

Memory is only an advantage if it can be trusted. This release hardens
every channel that feeds the agent's past into its present — and fixes
the live bugs the first real field runs surfaced.

### Fixed — the live-run class (first field reports)
- **The mesh panel no longer flashes and empties**: incremental chat
  reads replaced the buffer with only-new lines — one tick after the
  tail appeared, the panel went blank. Reads append now (bounded)
- **Cost lands every iteration**: the audit trail refreshes its cost
  from the provider accumulator (models.dev-priced) on EVERY turn — a
  window-close mid-run no longer dies at $0.000
- **Dead console redraws**: mascot frames are parsed once and cached
  (they were re-decoded from ANSI every frame); the dashboard runs on
  the alternate screen — the 20fps erase/reprint flash is gone
- **The hint row stays put** beside the input box while you type
- Detail-pane JSON boxes cap argument values (a python heredoc in `cmd`
  is not a spec — full payloads live in the audit trail); card
  severities are fully colored; phase counts read "N in exploitation"
  so they can't be misread as findings; the overview is one dense strip

### The key-confusion postmortem (three targets, one credential)
Concurrent engagements share the machine — and shared `/tmp` scratch
let one engagement read another's downloaded artifacts as its own. The
same credential was claimed by three different targets, entered the
knowledge graph, and the enforced per-turn graph read re-injected it
every turn until the verifier broke the loop. Fixes, one per stage:
- `execute_terminal` warns in-observation on literal `/tmp` use;
  the tool docs mandate workspace-home scratch and on-target
  verification before claiming a secret
- A credential literal already recorded under a different host is
  REJECTED at `record_finding` and at catalog CONFIRMED fan-out
  (www-normalized — same-site variants pass)
- The live graph was scrubbed; cross-target credentials quarantine to
  the workspace with the collision named

### Memory that can be trusted
- **Librarian target isolation**: every ledger observation carries its
  engagement target; `memory_recall` hides cross-target entries with a
  named count — a resumed ledger can no longer advise a different
  engagement (the lab-creds-in-a-production-run bleed)
- **Three-strike oracle rule**: the supervisor detects a question
  surviving repeated "decisive"/"one-shot" attempts and intervenes —
  switch oracle (browser, replay) or park it. Born from a spiral that
  cost ~19% of a real run
- **Stale-pause transparency**: a forgotten operator pause flag gated
  every new engagement forever, silently. Boot now prints a loud
  banner (age, reason, how to resume) and the console badge shows the
  flag's age
- `job_output` on a running job says so (was silent-empty — the source
  of poll/wait dances); finished-job results were already pushed into
  the next turn
- `write_file` returns the shell-usable absolute path first (the
  workspace-relative label was mistranslated twice in the field)
- The context manifest lists injected sections — `KNOWLEDGE_GRAPH` and
  `CHEATSHEET` sizes are visible while the run is live

### Neo4j polish
- `suijin[kg]` installs the backend driver; the Docker image carries
  it; fresh installs stay on the zero-dependency JSON default
- `suijin doctor` reports knowledge-graph REALITY: `neo4j (uri) — UP`
  or `— DOWN, running on json` (a configured-but-dead server read as a
  green check before)

### Tests
- The operator console gets its first suite (29 tests: digest-shape
  parity, roster semantics, chat increments, render-at-sizes, key and
  command routing, aggregation honesty) plus 21 hardening tests
  pinning every guard above — 2,840 green.
