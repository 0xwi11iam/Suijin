<h2 align="center">Release v5.7.0 — The Interactive Operator </h2>

## What's New Since v5.6.1
The operator and the AI are now in a live conversation: you type, the
AI reads, and you SEE the confirmation. The stream is clean. Bugs are
reproduced in a real PTY before they're fixed.

## What landed

**File-based live guidance** — the operator types a prompt in the input
box at ANY time (thinking or not) → it lands in
`engagement_dir()/live_guidance.md` → the think node reads it at the
TOP of the system prompt (above doctrine, above everything) → a GREEN
panel confirms: `» guidance — delivered to the AI: <text>`. The context
manifest (`context.md`) shows exactly what the AI was fed each turn.
Zero LangGraph state mutation — a file read is atomic and cannot fail.

**The adaptive typewriter stream** — prose types out at the model's
measured token rate (60 micro-increment gears, 20→3000 chars/sec);
think renders light dim-italic, speaking renders bold cyan; command
spans (`{"action"...}` JSON, fenced code) render as complete black
syntax boxes; duplicate command spans (the model rehearsing its own
decision) deduplicate. Model-emitted newlines are paragraph breaks.
The `still thinking… Ns` progress indicator fires every 15s (deduped,
suppressed during pause) so slow LLM calls never look like hangs.

**Classed vulnerability registration** — `catalog_exploit` with
agent-defined severity + CVSS: records display as
`CRITICAL CVSS 8.9 : SQL injection in the search parameter` in a
prominent TUI verdict panel (severity-colored). POC step-scripts run
through the terminal (the TERMINAL decides — no hallucination path).
Not-perfect results offer exactly three choices: EDIT (fixed poc),
ABANDON (memory-poisoned), or CLAIM IT WORKED ANYWAY (AI_CLAIMED,
amber-flagged "NOT terminal-verified" in every report).

**Per-engagement state** — `outputs/engagements/<stamp>_<slug>/` scopes
schema, recovery, scratchpad, and approvals. State dies with the run.
Ended engagements archive to `outputs/archive/` (the `.sje` bundle
remains the resume artifact). Recovery refuses garbage objectives
(pasted policy pages quarantine + start fresh). The scratchpad's
`[operator]` tags write as `[guidance-memory]` (the hallucination seed
is dead).

**`.sje` engagement bundles** — every concluded engagement saves a
hash-sealed zip (graph state + exploit catalogs + config with secrets
stripped). `suijin load <file.sje>` resumes with full memory.

**The interactive review rig** — `scripts/tui_drive.py`: spawn a real
engagement under a real PTY, drive with raw keystrokes (ESC ESC, Tab,
typing, /quit), read actual frames. Four field bugs caught live: the
prompt-eating `apply_key`, the TextIOWrapper ESC-swallowing, the
reader thread dying silently, and the pause-command queue stranding.

**Diagnostic logging** — `outputs/logs/diag.log`: every LLM call
(provider, model, TTFT, wall time), every tool call (name, duration,
backgrounded), every node transition. JSONL, rotates at 10MB. Any hang
is diagnosable post-mortem.

**The always-at-the-bottom input box** — `[recon|exploit|report] ·
[max|high|medium|low] · provider model » type here▌`. Tab cycles the
mode, Alt/Option+I cycles model intelligence (applies on the next LLM
call), ESC ESC pauses instantly (PAUSED strip, commands answer
immediately, guidance writes to the file). `/quit` ends with a full
save.

**Also**: ask-operator typing fixed (routes through the reader's ask
queue), 120s read timeout + 180s hard cap (was 300s/600s — the
invisible 10-minute stalls), kb_read returns the right doc (tiered
path matching), module-pack imports fixed (knowledge_graph, fileio,
search_cve), `/think` toggle renamed to "reasoning".
