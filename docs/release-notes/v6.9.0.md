# v6.9.0 — The Focus Release

The surface shrinks to what an operator actually uses, and the
durability story becomes one sentence: **the .sje bundle is it.**

### Removed — the focus cut
- Settings: supervisor model/interval knobs and the guardrail mode
  (the terminal safety floor stays — only the knob is gone)
- Mode picker: Blue Team and Settings unlisted (the code is retained
  and returns when the split lands)
- Operator Tools: exactly three — Resume (.sje), Replay engagement,
  Workspace cleaner
- Seven CLI verbs: `dossier scope approvals labs timeline battle
  debrief` (+ the CLI-only libs). Agent-side libs the tools still use
  (dossier intel, approvals HITL) stay

### Fixed
- **Replay sees history**: audit trails were split between the legacy
  `outputs/` path and engagement folders — every writer is
  engagement-scoped now and the picker enumerates every past engagement
- **Workspace cleaner rebuilt** for the real layout: engagement junk
  (`.sje.tmp`, job logs, garbage dumps), old logs, legacy leftovers —
  dry-run default, `--apply` archives then deletes, engagement data
  never touched
- Live models.dev pricing everywhere (the hardcoded table is the
  offline fallback, labeled approximate); coding-plan runs label USD
  as the PAYG equivalent
- MEM counts THIS engagement (run_id-scoped); /compact never refuses
  on message count and re-wires after provider restarts
- Reports are evidence-joined: catalog verification status per finding,
  reproduction sections from verified POCs, deterministic remediation
- The engagement folder stays in place at run end (archiving is opt-in)
- ESC is inert — pause is `/pause` or Ctrl+C, and the pause banner is
  one line

### Removed — the recovery machinery
`recovery.json` five-iteration snapshots, the startup resume gate, and
the legacy `operation_state_recovery.json` dump are gone. Crash
durability is the crash-saver's `.sje` — one mechanism, one story.

2,367+ tests green.
