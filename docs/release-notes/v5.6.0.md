## What's New Since v5.5.0
The blue team stops being a classifier and becomes a defender. A new
CTF lab gives both sides a proving ground — and the first release
published to container and package registries.

## What landed

**The Hill CTF** — a four-perimeter compound built for red-vs-blue. The
perimeter misdirects (decoy admin panels, a git bait, misleading
robots.txt; the real entry is unlisted and a decoy token validates
false). The foothold requires a JWT two-step (weak signing secret AND
alg:none acceptance) plus IDOR into docs that hold key fragments and
canary credentials. The pivot is SSRF through a webhook into an
internal-only metadata service — presenting the canary credentials there
gets you *deceived* with a fake keypair while tripping the loudest alarm
in the system. The vault encrypts the token with fragments scattered
across stages and a decryptor where command injection IS the extraction.
The token rotates every 15 minutes; a force-rotate lever lets blue
invalidate whatever red already stole.

**Blue Freedom (BF0–BF3)** — four waves that gave blue hands, a brain,
and a face:

- **Honesty first**: a confirmed attack can no longer pass with zero
  defense (unknown AI verdicts route to the fallback tarpit), the
  scoreboard counts what actually happened (detected vs blocked vs
  deceived), and sibling endpoints no longer get misattributed.
- **The arsenal**: every defense applies at the proxy — block an IP and
  its next request dies at the door, serve a honeypot and the attacker
  reads your words, arm a canary and its first use pages you, redirect,
  fake, rotate. Instant, zero app mutation. The namespaced tool registry
  (11 tools including a gated shell) cannot leak into red's prompts.
- **The org chart**: one primary agent (full think→act→observe loop,
  blue doctrine, eight defensive playbooks, creative-scripting freedom),
  per-endpoint watchers (zero-LLM, sub-second, auto-enforcing tarpit and
  block on critical hits while reporting), and summonable incident
  responders running bounded LLM episodes that route blue tools.
- **The console**: event blocks scroll as requests cross (request →
  verdict → action), a pinned strip tracks req · threats · blocked ·
  deceived · uptime, and an always-active input box takes /block,
  /unblock, /state, /canaries, /rotate, /shell — real-time command of a
  real-time defense.

**Publishing** — the Docker image now publishes to GHCR (multi-arch,
tagged per release) and the Python package to PyPI: `pipx install
suijin`. `docker compose run` works straight after clone.

## Try it

```bash
docker compose run --rm suijin      # or: pipx install suijin
suijin                              # Blue Team → hill_ctf → defend
```

Then point red at the proxy port blue prints. The rotating token is the
prize; force-rotate is the counter-move.
