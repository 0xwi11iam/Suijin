# Suijin v4.4.0 — Wave 1: Cost Control, Recipes, Planning

**Stable and ready.** First wave of the 50-feature roadmap: ten
features centered on money, reuse, and authoring.

## What's new

### The money features
- **Cost governor** — `max_cost_usd` in config.json hard-stops an
  engagement the moment spend crosses the line (checked before every
  LLM call; over-budget = `budget_exhausted` completion). A warn
  threshold (`cost_warn_pct`) steers the agent to wrap up first.
  Unpriceable models never brick runs.
- **Efficiency leaderboard** — `suijin status` now ranks engagements
  by findings-per-dollar with actions-per-dollar alongside.
- **Cost forecasting** — projections (mean/median/per-action) from
  your own engagement history, before you start the next one.
- **Failover telemetry** — `suijin doctor` shows provider-chain
  outcomes: primary-ok / failovers / all-down / last event.
- **Prompt budget profiler** — `suijin profile` renders where the
  tokens go (system vs history) and the per-iteration growth trend,
  with a warning when long engagements will hit context limits.

### The reuse features
- **Tool recipes** — named multi-tool macros with `{target}`/`{prev}`
  chaining: `recon_web`, `subdomain_sweep`, `email_recon` built in;
  define your own (`recipe_define` / `suijin recipes`).
- **Auto-recipe miner** — `suijin recipes mine` finds tool sequences
  that succeeded repeatedly across your engagement history and prints
  ready-to-adopt `recipe_define` calls. The agent's habits become
  reusable macros without anyone writing them.
- **Objective decomposer** — `suijin plan "<objective>"` produces a
  dependency-ordered subtask graph (LLM, with an offline heuristic
  spine as fallback).

### The platform features
- **Plugin test harness** — `suijin module test <name>`: the pack
  author's one-command pre-publish gate (files, schema, kernel boot,
  registration, catalog advertisement, callable smokes). It caught a
  real defect in a shipped pack within minutes of existing.
- **Wordlist hub** — `suijin wordlist list|fetch`: curated SecLists
  subsets fetched **sha256-verified** into the workspace (mismatches
  rejected — never feed unverified wordlists to brute tools).

## Upgrade
`install.sh` again (or `git pull` + pip install). Workspace state
migrates automatically as always. New config keys are optional:
`max_cost_usd`, `cost_warn_pct`.
