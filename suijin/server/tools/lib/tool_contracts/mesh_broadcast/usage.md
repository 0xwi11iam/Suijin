Broadcasts a message to all mesh peers (other running agents).

**Usage rules:**
- The message goes in the `message` argument — NOT in your thought
- Share: confirmed findings (so peers don't re-test), dead ends (so peers don't retry), lane claims (so peers don't duplicate)
- Keep messages actionable: "EXP-001 confirmed: JWT none-alg bypass on /api/auth — peers skip this surface"
